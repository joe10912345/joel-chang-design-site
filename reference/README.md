# reference/ 參考資料

| File 檔案 | What 內容 |
|---|---|
| `media-map.json` | Every site image: new name → original file, Wix crop, old Wix names, pages that use it. **Add new images here.** 每張網站圖片的對照（新名稱、原始檔、裁切、使用頁面）；**新增圖片要記錄在這裡**。 |
| `asset-sources.json` | Wix source URL of every downloaded file. 每個檔案的 Wix 來源網址。 |
| `archive/` | Export-era material kept for history: live-vs-local screenshots, side-by-side comparisons, responsive shots, update rounds `upd2`–`upd10`, lightbox and hover data, and `unused-wix-media/` (old Wix-named images no page uses; local only, not in git). 匯出時期的截圖、比對、舊圖等，僅供查閱。 |
| `rename-map-2026-11-27.json` | Old → new name of every file renamed in the 2026-11-27 clean-up (originals, videos, fonts, Wix CSS). 2026-11-27 整理時每個檔案的新舊檔名對照。 |
