# media-originals/ 原始大圖

Full-size originals the site images are made from (not online). One folder per page, named exactly like the site image
they belong to: `media-originals/<page>/<page>-<nn>-<w>x<h>.<ext>` ↔ `site/assets/media/<page>/<page>-<nn>-…`
(same page, same number). `_unused/` = originals no page uses. Old Wix names: `reference/rename-map-2026-11-27.json`;
which site file comes from which original: `reference/media-map.json`.

網站圖片的原始大圖（不上線）。一頁一個資料夾，檔名與網站圖片同頁名、同編號：
`media-originals/<頁名>/<頁名>-<編號>-<寬>x<高>` 對應 `site/assets/media/<頁名>/<頁名>-<編號>-…`。
`_unused/` 是沒有頁面使用的原始檔。舊的 Wix 檔名對照在 `reference/rename-map-2026-11-27.json`。
